## Major upstream functional changes

Anime4K 2× upscaling and line sharpening for Android ExoPlayer/mpv; subtitle shadow-outline blur across Android/iOS; forced-subtitle and AutoSync default behavior and restored-track fallbacks; shared/platform AutoSync transport and MP4 subtitle indexing; MPV error detail and playback-start/buffer/caption/network hardening; iOS playback-memory reductions, safer MPV teardown and PiP closure; authentication-session retention on refresh failure; MDBList anime episode remapping and reduced redundant tracking-list reads; coverage-aware/foreground-aware backdrop focus; and Bulgarian, French, Greek, Hebrew, Japanese, Vietnamese and other translation updates. Source tests, subtitle fixtures, shaders and the license notice are included. These imported source changes are not, by themselves, runtime/device validation.

## Manual resolutions and adaptations

- `HomeHeroSection.kt`: preserved StreamBridge home hero/library/wrap-frame behavior and added upstream backdrop reveal alpha and failed-image reset. The upstream `key` wrapper was not restored because StreamBridge deliberately removed it for existing frame/semantics behavior.
- `values-ja/strings.xml`: resource-key merge preserves local privacy, CloudStream and branding changes; imports upstream Japanese additions and updates; user-facing upstream brand references are adapted while the functional auth endpoint URL and attribution/disclosure strings remain intact.
- `values-he/strings_pip.xml`: upstream wording improvement applied with StreamBridge app name.
- `values-he/strings_party.xml`: StreamBridge brand and established three-placeholder invite with `%3$s` install fallback; Watch Party identity/redirect code unchanged.
- `iosApp/Configuration/Version.xcconfig`: upstream app version not imported; set to StreamBridge 0.1.17 / 117.
- `store.json`: upstream sideload metadata not imported; remains at the last verified published IPA until the existing published-release workflow verifies the real v0.1.17 IPA.
