# legacy/streambridge-app

Quarantined pre-Milestone-1 StreamBridge Android client
(`com.streambridge.app` custom Media3 / Compose app).

This module is **not** included in `settings.gradle.kts` and is **not**
built by CI. The running product is NuvioMobile (`:androidApp` +
`:composeApp`).
