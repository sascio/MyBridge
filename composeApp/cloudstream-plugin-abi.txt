# Plugin-facing ABI — classes a loaded CloudStream `.cs3` resolves BY NAME.
#
# A `.cs3` is compiled DEX loaded at runtime with PathClassLoader. It resolves
# host classes through their original JVM names, which R8 cannot see and will
# therefore shrink or rename. Debug builds are not minified, so a missing keep
# rule produces a build that passes every test and every CI check and then
# fails on the first provider call in the shipped release APK.
#
# That is exactly how "Failed resolution of: Lkotlin/collections/SetsKt;"
# shipped: AllMovieLandProvider.cs3 calls
# `kotlin.collections.SetsKt.setOf([Ljava/lang/Object;)Ljava/util/Set;`
# and R8 had removed that multifile facade from the release APK.
#
# This file is the single source of truth for two independent checks:
#
#   * CloudStreamMinificationRulesTest  -> every `keep` package has a -keep rule
#                                          in proguard-cloudstream-full.pro
#   * .github/verify-cloudstream-apk.py -> every `probe` descriptor is really
#                                          present in the built Full APK's dex,
#                                          release (minified) included
#
# The probe list is not a guess. It was derived by parsing the DEX type tables
# of 50 `.cs3` packages published by a real CloudStream repository; the
# `refs` comment on each line is how many of those 50 reference that package.
#
# Format (tab or spaces separated):
#   keep  <java.package.prefix>
#   probe <JVM/type/Descriptor;>
#
# Only probe packages this build genuinely ships: a -keep rule on an absent
# library legitimately keeps nothing, and probing it would fail spuriously.

# --- The CloudStream runtime ABI itself (refs: 50/50) -----------------------
keep  com.lagradost
probe Lcom/lagradost/cloudstream3/MainAPI;
probe Lcom/lagradost/cloudstream3/plugins/BasePlugin;
probe Lcom/lagradost/cloudstream3/utils/ExtractorLink;
probe Lcom/lagradost/cloudstream3/utils/ExtractorApi;
probe Lcom/lagradost/cloudstream3/SubtitleFile;
probe Lcom/lagradost/nicehttp/Requests;
