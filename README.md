# MyBridge Phase 1A — Real Server Foundation

This is the first functional foundation of MyBridge.

## Included
- Android app
- Real local HTTP server using `ServerSocket`
- Automatic LAN IPv4 detection
- `/health`
- `/manifest.json`
- Stremio-shaped `/catalog/...`, `/meta/...`, `/stream/...` placeholders
- CORS headers
- Hero-style dashboard
- No bundled/default extensions
- No TMDB/MDBList integrations enabled

## Not included yet
- CloudStream extension runtime
- Real provider/search/stream extraction
- QR generation
- Install in Stremio action
- TMDB/MDBList integration

Those belong to later phases.
